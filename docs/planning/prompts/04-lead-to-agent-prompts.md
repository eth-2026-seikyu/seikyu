\### ENSv2 Permissioned Registry API
- `register(label, owner, registry, resolver, roleBitmap, expiry)` (expiry is an ABSOLUTE timestamp), `renew(anyId, newExpiry)` (cannot reduce), `unregister(anyId)`, `setSubregistry(anyId, registry)`, `setResolver(anyId, resolver)`, `grantRoles(anyId, roleBitmap, account)`, `revokeRoles(...)`, `grantRootRoles(roleBitmap, account)`, `getState(labelhash)`.
- Expiry: name is expired when `block.timestamp >= expiry`; `ownerOf()` returns address(0); state becomes AVAILABLE; `renew()` revives with same owner/roles; re-register burns old token.
- Roles (bit positions): `ROLE_REGISTRAR = 1<<0`, `ROLE_UNREGISTER = 1<<12`, `ROLE_RENEW = 1<<16`, `ROLE_SET_SUBREGISTRY = 1<<20`, `ROLE_SET_RESOLVER = 1<<24`, `ROLE_CAN_TRANSFER_ADMIN = (1<<28)<<128`; admin variant = `role << 128`. When initializing a UserRegistry the roleBitmap must include at least `ROLE_REGISTRAR_ADMIN` and `ROLE_RENEW_ADMIN` or you cannot grant those roles later.
- Deploy your own subname registry: UserRegistry proxy via VerifiableFactory → parent owner calls `setSubregistry(labelhash(parentLabel), userRegistryAddr)` on ETHRegistry → grant `ROLE_REGISTRAR | ROLE_RENEW` on the UserRegistry to your registrar contract via `grantRootRoles`. The official tutorial ships `SimpleSubnameRegistrar` (Foundry) whose `register(label, owner, resolver, duration)` calls `REGISTRY.register(...)` with `block.timestamp + duration` and grants owner `ROLE_SET_SUBREGISTRY | ROLE_SET_SUBREGISTRY_ADMIN | ROLE_SET_RESOLVER | ROLE_SET_RESOLVER_ADMIN | ROLE_CAN_TRANSFER_ADMIN`. Tooling: `forge init` + `forge install ensdomains/contracts-v2`, remappings `@ensdomains/contracts-v2/=lib/contracts-v2/contracts/src/`, viem for scripts. Token IDs are mutable — index by labelhash.
\### ENSv2 Permissioned Resolver
- One UUPS proxy resolver per account, deployed via VerifiableFactory with `initialize(grants, calls)`; point the name at it with `setResolver`.
- Per-record permission: build a "setter" = `encodeFunctionData({functionName:'setText', args:['0x', 'status', '']})` then `grantSetterRoles(setter, account)` → that account may only call `setText` for key `status`. Resource for string args = `keccak256(bytes(key))`. Also `grantRootRoles/revokeRootRoles/revokeRoles(resource, roleBitmap, account)`.
- Aliasing: `linkToNode(sourceName, targetNode)`, `linkToRecord(sourceName, recordId)`.
