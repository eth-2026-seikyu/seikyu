# สคริปต์พรีเซนต์ ชุดหลัก (`main.html`) — ภาษาไทย

ใช้คู่กับ `main.html` 13 หน้า ยาวประมาณ **3 นาทีครึ่ง** — ลำดับหน้าและจังหวะ
เวลาตรงกับฉบับภาษาอังกฤษ [`script-main.md`](script-main.md) ทุกหน้า ถ้าพรีเซนต์
เป็นภาษาอังกฤษให้ใช้ไฟล์นั้น ไฟล์นี้ไว้ซ้อม หรือใช้ตอนพูดกับผู้ฟังคนไทย

ศัพท์เทคนิคคงไว้เป็นภาษาอังกฤษตามที่ใช้กันจริง (ENS, World ID, ERC-721, Sepolia,
record, revert) ไม่ต้องแปล

เปลี่ยนหน้าด้วย → หรือ space · กด `f` เต็มจอ

ตัวเลขให้พูดช้า ๆ ถ้าเวลาไม่พอ ข้ามทีละข้อดีกว่าเร่งพูด

- **เหลือ 3 นาที** → ตัดที่มาของชื่อในหน้า 1 (ย้ายไปตอบตอนถาม)
- **เหลือ 2 นาทีครึ่ง** → ตัดหน้า 3 กับ 7 เพิ่ม
- **เหลือ 2 นาที** → ตัดหน้า 3, 7 และ 12 — เรื่องยังจบได้

## 1 — Seikyu 請求 *(0:00–0:18)*

"Seikyu มาจากคำว่า 請求 ในภาษาญี่ปุ่น อ่านว่า เซคิว แปลว่าการเรียกร้อง หรือการ
ทวงถามให้ชำระเงิน เติมอีกตัวคือ 書 ที่แปลว่าเอกสาร จะกลายเป็น 請求書 ซึ่งแปลว่า
ใบแจ้งหนี้ เราเลือกคำแรก ไม่ใช่คำที่แปลว่าเอกสาร เพราะสิ่งที่ซื้อขายกันในระบบนี้
คือสิทธิเรียกร้อง ไม่ใช่ตัวกระดาษ

สรุปตัวโปรดักต์ในประโยคเดียว: รับเงินวันนี้ จากใบแจ้งหนี้ที่ยังไม่ถึงกำหนดอีก
60 วัน ตอนนี้ใช้งานได้จริงบน Sepolia แล้ว"

## 2 — ปัญหา *(0:18–0:36)*

"เริ่มจากปัญหาก่อน ผู้ขายส่งงานเสร็จวันนี้ แต่ได้เงินอีก 60 ถึง 90 วัน
เงินเดือนพนักงานไม่รอ 60 วัน ค่าวัตถุดิบก็ไม่รอ จะเอาใบแจ้งหนี้ไปกู้ธนาคารก็ได้
แต่ต้องมีหลักประกัน มีเอกสาร แล้วรออีกสองสัปดาห์ ซึ่งคือเงินกับเวลาที่เขาไม่มี
อยู่พอดี"

## 3 — ทำไมไม่มีใครซื้อไปเลย *(0:36–0:52)*

"ทางออกที่ชัดที่สุดคือขายใบแจ้งหนี้ให้คนที่มีเงินสด แต่ใบแจ้งหนี้คือไฟล์ PDF
และ PDF พิสูจน์อะไรไม่ได้เลย ส่งงานจริงหรือเปล่า มีแต่ลูกหนี้ที่รู้ ขายซ้ำให้คน
อื่นไปแล้วหรือยัง ก็ไม่มีทางรู้ ค่าตรวจสอบแพงกว่าส่วนลดที่จะได้ สุดท้ายเลยไม่มี
ใครตรวจ แล้วผู้ขายก็ต้องรอต่อไป"

## 4 — ทางแก้ *(0:52–1:08)*

"เราเลยทำให้ใบแจ้งหนี้ตรวจสอบได้ หน้าแรกบอกสามบทบาทด้วยภาษาคนทั่วไป ผู้ขายลง
ใบแจ้งหนี้ที่ยังไม่ได้รับเงิน นักลงทุนซื้อวันนี้ในราคาส่วนลด บริษัทลูกหนี้ยืนยัน
ว่าหนี้จริง แล้วจ่ายเต็มจำนวนวันครบกำหนด ทั้งหน้านี้ไม่มีศัพท์คริปโตสักคำ"

## 5 — ทำงานยังไง *(1:08–1:32)*

"ทั้งดีลอยู่ในภาพเดียว วันนี้: ผู้ขายลงใบแจ้งหนี้ เซ็นครั้งเดียว ได้ชื่อ ENS ที่
หมดอายุตรงวันครบกำหนดหนี้ ฝ่ายบัญชีของลูกหนี้ยืนยันว่าใบนี้จริง ฝั่งคนซื้อพิสูจน์
ด้วย World ID ว่าเป็นคนจริงหนึ่งคน แล้วจ่าย 950 เข้าผู้ขายโดยตรง ไม่มีพักไว้ที่ใคร
จากนั้นสิทธิ์ในใบแจ้งหนี้ย้ายไปเป็นของเขา อีก 60 วันลูกหนี้จ่ายเต็ม 1,000
แล้วชื่อนั้นก็หมดอายุไปพร้อมกับหนี้"

## 6 — เซ็นครั้งเดียว *(1:32–1:48)*

"การออกใบแจ้งหนี้คือการเซ็นครั้งเดียวนั้น ธุรกรรมเดียวทำสามอย่าง: mint token ที่

`inv-15.seikyu.eth` โดยตั้งวันหมดอายุเท่ากับวันครบกำหนด อายุของชื่อคืออายุของหนี้"

## ถ้าโดนถาม

- **"Seikyu แปลว่าอะไร"** — 請求 (เซคิว) ภาษาญี่ปุ่น แปลว่าการเรียกร้อง หรือการ
  ทวงถามให้ชำระเงิน เติม 書 (โช แปลว่าเอกสาร) เป็น 請求書 ถึงจะแปลว่าใบแจ้งหนี้
  ที่ส่งให้ลูกค้า เราเลือกคำสั้นโดยตั้งใจ เพราะกระดาษยังอยู่กับผู้ขาย สิ่งที่
  นักลงทุนซื้อคือสิทธิเรียกร้อง
- **"เงินจริงหรือเปล่า"** — ไม่จริง เป็น Sepolia testnet กับ mock USDC ในแอป
  ขึ้นแจ้งไว้ทุกหน้า ไม่มีอะไรที่นี่มีมูลค่าจริง
- **"ทำไมต้อง ENS ไม่ใช้ database"** — เพราะวันหมดอายุทำงานจริง วันครบกำหนดหนี้
  กับอายุของชื่อเป็นข้อมูลเดียวกัน บันทึกเลยเพี้ยนจากหนี้ไม่ได้ และใครก็ตรวจสอบ
  ใบแจ้งหนี้ได้เองโดยไม่ต้องมาถามเรา
- **"อะไรกันใบแจ้งหนี้ปลอม"** — wallet ฝ่ายเจ้าหนี้การค้าของบริษัทลูกหนี้เองเป็น
  คนยืนยันหรือ dispute บน chain และใบที่ถูก dispute ซื้อไม่ได้ เราไม่ได้รับรอง
  ใบแจ้งหนี้ ลูกหนี้เป็นคนรับรอง
- **"ทำไมใช้ World ID ไม่ทำ KYC"** — เราต้องการความเป็นคนคนเดียว ไม่ได้ต้องการ
  รู้ว่าเป็นใคร เพดานสามใบต่อคนจะมีความหมายก็ต่อเมื่อคนเดียวเปิดสิบ wallet ไม่ได้
- **"ถ้าลูกหนี้ไม่จ่ายเลย"** — ใบแจ้งหนี้จะขึ้นสถานะเกินกำหนด ใครก็ต่ออายุชื่อ ENS
  ได้อีก 30 วัน เพื่อให้บันทึกยังอยู่ระหว่างตามหนี้ เราไม่ได้อ้างว่านักลงทุน
  ได้เงินแน่นอน
- **"ใครรับความเสี่ยง"** — นักลงทุน โดยรู้ตัว ส่วนลดคือราคาของความเสี่ยงนั้น และ
  การที่ลูกหนี้ยืนยันบน chain คือสิ่งที่ทำให้ความเสี่ยงนั้นคุ้มที่จะรับ
- **"ทำในแฮกกาธอนจริงหรือเปล่า"** — จริง เขียนใหม่ทั้งหมด โดยให้ AI agent เขียน
  โค้ดเป็นส่วนใหญ่ แผน prompt และคำชี้แจงการใช้ AI ทั้งหมด commit อยู่ใน repo
  ใต้ `docs/`
